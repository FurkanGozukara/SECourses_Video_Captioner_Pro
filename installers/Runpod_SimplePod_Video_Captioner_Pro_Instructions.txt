Start a new terminal

To install run below command

export UV_THREADPOOL_SIZE=8
cd /workspace
export HF_HOME="/workspace"
chmod +x RunPod_Install_SECourses_Video_Captioner_Pro.sh
./RunPod_Install_SECourses_Video_Captioner_Pro.sh

Keep HF_HOME on /workspace (or another persistent mounted volume with enough free space) in every new terminal so cache files survive pod restarts.

The installer prepares Python 3.12 and builds the pinned CUDA llama.cpp runtime used by GGUF model variants. If that best-effort build reports a warning, open the System & Models tab after launch and click Install / repair llama.cpp to retry it.

Models download automatically on first use in SECourses Video Captioner Pro.
To open the downloader menu manually:

cd /workspace
SECourses_Video_Captioner_Pro/venv/bin/python Models_Downloader.py

The menu includes Qwen3-Omni Instruct, Thinking, and Captioner GGUF Q4_K_M and Q8_0 entries. GGUF also needs the pinned CUDA llama.cpp build that the installer performs automatically; the System & Models tab is the retry path if the first build did not complete.

To run the app again after installation later run below command

export HF_HOME="/workspace"
cd /workspace
cd SECourses_Video_Captioner_Pro
git pull
source venv/bin/activate
python secourses_app.py --share

The app selects the venv's CUDA 13 libraries and repairs older CUDA 12 Whisper/cuDNN dependencies automatically. To run the repair explicitly: python -m vcap.core.cuda_runtime --repair
